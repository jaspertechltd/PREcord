⚡ Bolt: [performance improvement] Cache JSON Metadata

💡 What: Implemented a `ConcurrentHashMap` in `CaptureMetadataStore` to cache parsed JSON metadata.
🎯 Why: Reading metadata from disk synchronously causes N+1 performance jank, especially when rendering lists in Jetpack Compose.
📊 Impact: Eliminates blocking disk I/O on repeated reads, removing significant UI stutter and lowering latency on list scroll.
🔬 Measurement: Verify by scrolling a list of captures in the UI; frame drops and stutter should be measurably reduced.
