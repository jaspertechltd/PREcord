🎨 Palette: Added helpful empty state to Captures list

💡 What:
Added a visually distinct empty state to the `CapturesScreen`. The new UI presents a friendly icon, an explanatory title, and a helpful description to guide the user.

🎯 Why:
Previously, opening the captures list when there were no saved items or active search results displayed a blank page, which is confusing and feels unpolished. This provides clear contextual guidance on why the list is empty (e.g., no items recorded yet vs no search matches found) and instructs users on what to do next.

♿ Accessibility:
Replaces an empty `LazyColumn` with explicit content, ensuring that screen readers won't just hit a dead end and users understand the current state of the app without guessing.
